# OWCS OB Analyzer 0.6.1

守望先锋 OB 计分板识别插件，支持英雄、威能中文显示，以及 HTTP / WebSocket 数据输出。适用 Windows 10/11 x64、OBS Studio 30.0 及以上，无需另外安装 Python 或启动服务。

## 安装与使用

1. 解压安装包并退出 OBS。
2. 将 `obs-plugins` 和 `data` 两个文件夹复制到 **OBS 安装根目录**，与原目录合并。Steam 版同样适用。
3. **每次以管理员身份启动 OBS**：右键快捷方式或 `obs64.exe`，选择“以管理员身份运行”。也可在快捷方式“属性 → 高级”中勾选“用管理员身份运行”。
4. 在显示游戏画面的视频源中，打开“滤镜 → 效果滤镜 → +”，添加“OWCS 观战数据识别”。
5. 在“停靠窗口”菜单打开“OWCS 观战数据”，即可查看、复制或导出识别结果。

本机观战可在滤镜属性中开启“自动按住 Tab”，切回游戏后自动显示计分板。支持窗口、游戏、显示器、媒体文件和采集卡等视频源。

遇到一直按住 Tab 后威能图标消失的地图，可在 **视频源 → 滤镜 → OWCS 观战数据识别的滤镜属性** 中开启“定时重按 Tab”，默认关闭；重按间隔默认 10 秒，可设为 2–300 秒。仅在自动 Tab 开启、识别允许操作且本机守望先锋位于前台时生效。每次松开至少 250 毫秒，再在后续采样周期重新按住；低采样率时关闭面板的时间会更长。切出游戏、停止识别或关闭自动 Tab 时释放按键。录像和采集卡无需开启自动按键。

同一选手、同一英雄已经确认的威能不会因图标消失、空槽或布局收起而被清除，会显示为灰色历史值，重新识别后恢复正常。换英雄、明确取消选英雄或清空数据会清除对应记忆；另一位选手不会继承。插件无法自动判断新一局是否开始，换局或回放倒退后请使用“清空数据”，避免保留旧局的威能。

表格第一列可编辑“优先级”：数字越小越靠前，范围 1–9999，默认 1000；按回车或离开输入框后保存。相同优先级按面板位置排列，已确认离场者始终置后。优先级绑定选手 ID，换行、换边和重连后仍跟随该选手，所有来源共用，重启 OBS 后保留。“恢复默认顺序”清除全部优先级设置。此顺序同时用于面板、HTTP/WebSocket、复制与导出的 JSON；数据归属和队伍不变。

已知限制：徽章、动态名牌、头衔和部分中文昵称可能影响姓名识别。从未确认姓名的行暂不进入选手列表，因此列表可能不足十人；0.6.1 尚未修复此问题。

在停靠面板点击“选手名单”：搜索 Liquipedia 赛事（也可粘贴赛事链接），选择后导入；下方可手动添加、修改或删除昵称，每行一个，保存后生效。所有选手共用一个名单，不分队伍。匹配支持易混字符和高相似度名字，短名字更严格；名单未匹配或候选有歧义时使用原始 OCR 名字。停靠面板显示基于英雄的职责。表格按已确认的选手名字保留行身份，Tab 补位只改变位置列。离场时保留该选手上次确认的数据并显示为灰色；重连确认身份后读取新的 E/A/D、伤害、治疗、抵挡，包括归零或较小的数值，不累加。暂时遮挡或姓名不清楚时显示待确认。换地图或需要重新识别时，可点击面板底部的“清空数据”：只清空当前来源的选手记录与历史，保留选手名单和接口设置；识别继续运行，新画面会自动填入数据。修改名单或关闭再开启“启用识别”也会重置识别会话。

也可在解压目录使用安装脚本，自动校验文件并备份旧版本：

```powershell
powershell -ExecutionPolicy Bypass -File .\Install.ps1 -ObsPath 'C:\Program Files\obs-studio'
```

将路径替换为实际 OBS 安装目录；目录需要写入权限时使用管理员 PowerShell。升级时先退出 OBS，再安装完整新版包。卸载使用 `Uninstall.ps1 -ObsPath '实际安装目录'`。

## 开发与接入

0.6.0 起使用 API v4：只保留一份 `players`，按 `player_id` 绑定选手，`team` 分队，`stale_fields` 标记历史值，未知为 null。旧的物理行数组、重复选手集合和内部身份字段不再输出；升级调用方需同步接口结构。

- HTTP：`http://127.0.0.1:8765/v1/state`
- WebSocket：`ws://127.0.0.1:8765/v1/state-stream`
- 停靠面板可设置端口和局域网访问。
- 接口文档：[docs/STATE_API.md](docs/STATE_API.md)。
- 资源维护：[docs/RESOURCE_PACKS.md](docs/RESOURCE_PACKS.md)。
- 源码与构建指南：[GitHub](https://github.com/Wine-Red/owcs-ob-analyzer)。
