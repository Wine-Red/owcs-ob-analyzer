# OWCS OB Analyzer 0.4.0 安装与使用

适用 Windows 10/11 x64、OBS Studio 32.2.2。无需安装 Python，无需另外启动识别服务。插件附带模型，运行时不下载文件。

支持问号头像的“未选英雄”状态。未选时仍读取姓名与可见统计，英雄、大招、威能和生存状态保持未知，不沿用上一英雄。HUD 校验不再限定蓝／红队色，但仍依赖标准十人布局及可读画面，任意字体、超宽屏和重排的赛事包装不保证通用。

英雄和威能资源可通过独立资源包更新，完整操作见 `docs/RESOURCE_PACKS.md`。资源包需要先安装本插件，再退出 OBS、校验安装并重启；放入单张 PNG 不会自动生效。

## 安装

1. 解压安装包。退出要安装插件的 OBS。
2. 将包中的 `obs-plugins` 和 `data` 两个目录复制到 **OBS 安装根目录**，与原目录合并。Steam 版也支持，例如 `E:\SteamLibrary\steamapps\common\OBS Studio`。
3. 启动 OBS。在某个视频源的“滤镜 → 效果滤镜 → +”中添加“OWCS 观战数据识别”。
4. 在“停靠窗口”菜单打开“OWCS 观战数据”。

也可以在解压目录执行安装脚本，它会验证文件校验值并备份覆盖的旧插件文件：

```powershell
powershell -ExecutionPolicy Bypass -File .\Install.ps1 -ObsPath 'E:\SteamLibrary\steamapps\common\OBS Studio'
```

若 OBS 安装目录需要写入权限，在管理员 PowerShell 中执行安装脚本。卸载使用同目录 `Uninstall.ps1 -ObsPath '...'`，只移除本版本清单中未被修改的插件文件，保留场景和配置。升级时先退出 OBS。

## 使用

选择能正常显示完整游戏画面的来源。支持窗口、游戏、显示器、媒体文件、图片、采集卡等视频源；插件读取所附着源的图像，不绑定某一种采集方式。

默认启用识别和姓名 OCR，分析频率为 5 fps。计分板连续确认后，停靠窗口显示十人状态；姓名需要约数秒多轮确认。切换数据源可在窗口顶部选择，多源分别使用独立 `stream_id`。

本机 OB 自动打开面板：在滤镜属性中启用“自动按住 Tab”，切回带十人 HUD 的守望先锋 OB 窗口。只有游戏处于前台、HUD/计分板确认后才发送按键。游戏以管理员运行时，OBS 也需要管理员权限。视频文件和远端采集卡通常保持此选项关闭。前台切走、停止、断帧或移除滤镜会释放插件持有的 Tab。

按住 Tab 本身会让原游戏画面显示计分板。若需要干净直播画面，应使用独立 OB 客户端/信号用于采集数据；此插件不会自动擦除计分板。

## 数据输出

默认仅本机：

- `http://127.0.0.1:8765/health`
- `http://127.0.0.1:8765/v1/streams`
- `http://127.0.0.1:8765/v1/state`
- `ws://127.0.0.1:8765/v1/state-stream`

在停靠窗口可以更改端口、允许局域网、复制或导出 JSON。允许局域网后，接口对可访问该端口的设备提供只读数据，无账号认证；需要用本机实际 IP 连接。端口冲突会显示错误，可更换端口。

停靠表格保留最后一次结果，过期值显示为灰色，并提示“非实时”。精简 API 使用 `stale_fields` 和 `unknown_fields` 标识过期及未知字段，缺失为 `null`。详情见 `docs/STATE_API.md`。

## 黑屏和未识别

插件依赖 OBS 来源实际提供图像，不能从已经黑屏的来源恢复内容。先禁用识别滤镜检查 OBS 来源本身：

- 窗口采集：在属性中显式尝试“Windows 10（1903 及以上）”采集方式；游戏使用无边框窗口，测试时保持显示而非最小化。
- 游戏采集：检查目标进程和双方权限；本机此前日志出现无法打开 Overwatch 进程，游戏管理员/OBS 普通权限是具体原因之一。
- 双显卡机器：检查 OBS 与游戏使用的显卡；也可先测试显示器采集，确认基本图像链路。
- 媒体/采集卡：保证信号中计分板完整、清晰且没有遮挡。可通过前置裁剪移除额外黑边。

来源不再渲染时不会持续识别。中文选手名可能存在同形字误读；未知英雄和威能会保留未知，不用猜测补齐。

0.4.0 将全部对外数据输出统一为精简 schema 3.0：业务字段移到选手对象直属层，去掉置信度、定位与性能信息；HTTP/WS 路径不变，旧调用方需按 `docs/STATE_API.md` 迁移。
