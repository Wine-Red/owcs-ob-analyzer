# OWCS OB Analyzer 用户使用说明

OWCS OB Analyzer 是面向《守望先锋》自定义房间实时观战的 Windows 工具。它读取游戏顶部十名选手栏，持续输出：

- 选手 ID（支持正式比赛常见的英文 ID，也支持中文测试 ID）；
- 当前英雄；
- 生存状态（存活、阵亡或未知）。

识别结果会显示在透明浮层中，也会通过局域网 HTTP/WebSocket 接口提供给直播包装程序。程序不会根据队伍卡片的红色、蓝色或其他背景颜色判断队伍。

## 使用要求

- Windows 10/11 64 位。
- 游戏内“宽高比”设置为 **16:9**。这是本软件的主要且正式支持布局。
- 建议使用无边框窗口或窗口模式，并保持 Overwatch 窗口可见。
- 进入自定义房间的观战画面，并确保顶部十名选手栏完整显示。

如果 Windows 显示器或无边框客户区是 16:10（例如 2560×1600），只要游戏内仍使用 16:9 的 HUD 布局，软件通常也能兼容；这不是独立的 16:10 游戏布局支持。其他游戏内宽高比目前不保证识别准确。

## 启动

1. 将 ZIP 完整解压到一个可写文件夹，例如 `D:\Tools\OWCSOBAnalyzer`。
2. 不要单独移动 EXE，也不要删除旁边的 `_internal` 文件夹。
3. 双击 `OWCSOBAnalyzer.exe`。
4. 打开 Overwatch 观战窗口后，点击“开始识别”。
5. 状态显示“实时识别中”后即可使用。

首次启动可能出现 Windows 防火墙提示。这是因为程序默认提供局域网状态接口；只有需要让另一台直播包装电脑连接时，才需要允许可信的专用网络访问。

## 浮层与快捷键

- `Ctrl+Alt+H`：显示或隐藏全部分析浮层。
- `Ctrl+Alt+I`：把工具及时间线重新带到前面。
- 控制条可直接拖动；左侧整体时间线可以点击并按选手或事件筛选。
- 点击控制条的 `×` 会停止识别并完全退出程序。

选手栏附近的卡片会显示已确认的选手 ID、英雄、生存状态和最近事件。ID 或英雄尚未达到确认条件时，软件会保留未知或显示原始名字条，不会用低置信结果强行替换。

## 给直播包装程序的数据接口

默认接口：

- 当前状态：`http://识别电脑IP:8765/v1/state`
- WebSocket 状态流：`ws://识别电脑IP:8765/v1/state-stream`
- 健康检查：`http://识别电脑IP:8765/health`

跨电脑使用时，两台电脑需要位于可互通的局域网，并在识别电脑的 Windows 防火墙中允许 TCP 8765。直播包装应始终使用 `slot_id` 作为十个位置的稳定主键，不要使用队伍颜色或选手名字作为主键。

接口字段和示例见 `docs/STATE_API.md`。

## 常见问题

### 一直显示“定位选手栏”

- 确认游戏内宽高比是 16:9。
- 确认顶部十名选手栏没有被裁切、遮挡或移出屏幕。
- 确认当前确实处于能显示完整双方选手栏的观战界面。
- 尝试使用无边框窗口，并重新点击“开始识别”。

### 某个 ID 或英雄暂时显示未知

这是安全策略。程序需要连续多次得到一致结果才会发布；短暂动画、遮挡或低对比画面不会立刻覆盖已经确认的状态。保持顶栏可见数秒即可。

### 快捷键没有反应

检查是否有其他软件占用了 `Ctrl+Alt+H` 或 `Ctrl+Alt+I`。即使快捷键冲突，控制条上的按钮和左侧时间线仍可直接点击。

### 直播包装电脑连接不上

- 使用识别电脑的局域网 IP，不要在另一台电脑上使用 `127.0.0.1`。
- 确认两台电脑能互相访问。
- 检查 Windows 防火墙是否允许该程序或 TCP 8765。
- 在识别电脑浏览器打开 `http://127.0.0.1:8765/health` 检查服务。

## 当前范围

当前版本不处理比赛阶段划分、暂停、击杀播报或大招释放事件。正式输出聚焦于十个固定槽位的选手 ID、英雄和生存状态。
